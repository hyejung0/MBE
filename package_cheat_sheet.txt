2. CREATING AND DOCUMENTING FUNCTIONS
-------------------------------------------------------------------------------

# 1. Create a new R script in R/
usethis::use_r("function_name")

# 2. Write the function, place the cursor inside it, and insert a roxygen
#    documentation skeleton:
#      Mac:     Cmd + Option + Shift + R
#      Windows: Ctrl + Alt + Shift + R
#      Menu:    Code -> Insert Roxygen Skeleton

# 3. Complete the relevant roxygen2 fields:
#' @description Explain what the function does.
#' @param arg1 Explain the first argument.
#' @param arg2 Explain the second argument.
#' @return Describe the returned object and its structure.
#' @export
#' @examples
#' result <- function_name(arg1, arg2)

# 4. Regenerate documentation after changing roxygen2 comments
devtools::document()

# Notes
# - Use @export only for functions that should be part of the public API.
# - Wrap slow examples in \donttest{} (or \dontrun{} if they cannot run on
#   CRAN), so devtools::check() stays fast.
# - Use @importFrom pkg fun (or pkg::fun()) rather than library() in package
#   code.
# - Never edit NAMESPACE or man/*.Rd by hand; they are generated.

6. VIGNETTES THAT RUN STAN (PRECOMPUTED VIGNETTE WORKFLOW)
-------------------------------------------------------------------------------

Use this when a vignette executes Stan code (rstan or cmdstanr). Stan is slow
and needs a compiler, so we knit locally and commit only the static output.
That way CI and CRAN need neither rstan, CmdStan, nor cmdstanr to build it.

Suppose the vignette is called name.Rmd.

1. Create and develop the vignette as usual:
     usethis::use_vignette("name")
   Make sure it knits with no errors locally.

2. Rename the source so it is never built directly:
     name.Rmd  ->  name.Rmd.orig
   (Keep editing name.Rmd.orig from now on, never the generated name.Rmd.)

3. Knit from inside vignettes/ so figure paths come out relative to the
   vignette:
     old <- setwd("vignettes")
     knitr::knit("name.Rmd.orig", output = "name.Rmd")
     setwd(old)
   (Knitting from the package root with
   knitr::knit("vignettes/name.Rmd.orig", output = "vignettes/name.Rmd")
   also works, but check that the figure links in name.Rmd point to files that
   actually exist in vignettes/.)

4. Commit the knitted name.Rmd AND its generated figure files.
   Do NOT commit name.Rmd.orig as a vignette source to be built; see step 5.

5. Keep .orig files out of the built package. Add this line to .Rbuildignore:
     ^vignettes/.*\.orig$

6. Check the result:
     devtools::check()
     pkgdown::build_article("name")

Re-run steps 3-4 every time the Stan model, data, or vignette text changes.
Tip: set a seed at the top of the .orig file so the committed output is
reproducible.

10. TROUBLESHOOTING
-------------------------------------------------------------------------------

Function not found after editing:
  Run devtools::document() (exports) and devtools::load_all().

"Undocumented arguments" or NAMESPACE warnings in check():
  Add the missing @param / @export, then devtools::document().

New function missing from the website:
  Add it to the reference section of _pkgdown.yml, then
  pkgdown::check_pkgdown().

pkgdown Action fails on a Stan vignette:
  The vignette was probably not precomputed. Redo Section 6 and confirm
  name.Rmd contains static output with no live Stan chunks.

Check complains about non-standard files in the top-level directory:
  usethis::use_build_ignore("file_or_folder").

Website looks stale:
  Confirm the Action succeeded, then hard-refresh the browser (Cmd/Ctrl +
  Shift + R).


===============================================================================
                    11. STANDARD WORKFLOW FOR UPDATING THE PACKAGE
===============================================================================

 1. Pull the latest changes (git pull) and confirm the working tree is
    understood (git status).
 2. Edit functions, tests, documentation, data, or vignettes as needed.
 3. Use devtools::load_all() for quick interactive checks.
 4. Run devtools::document() after changing roxygen2 comments or exports.
 5. Run devtools::test() and fix any failures.
 6. Run devtools::build_readme() if README.Rmd changed.
 7. If a Stan vignette changed, re-knit it (Section 6).
 8. Add a NEWS.md entry for any user-visible change (bump the version if
    releasing).
 9. Run devtools::check(); aim for 0 errors, 0 warnings, and 0 notes.
10. Optionally run pkgdown::build_site() and pkgdown::preview_site() locally.
11. Review git status and the diff, then commit and push the source changes.
12. Confirm that the R CMD check and pkgdown GitHub Actions both succeed.
13. Confirm the deployed website at https://hyejung0.github.io/MBE/.
